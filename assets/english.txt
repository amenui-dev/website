一页文字通常被看成一个方框：框里是字，框外是别的东西。可是纸上从来不是这样排的。报纸的版面里，照片的边缘是不规则的，文字沿着它走；手抄本里，大写字母占了好几行，后面的字绕开它。字和图之间留着一条均匀的缝，缝的形状就是图的形状。 = A page of text is usually taken as a box: text inside, everything else outside. Paper was never set that way. On a newspaper page a photograph's edge is irregular and the text follows it; in a manuscript an initial takes several lines and the text goes round it. An even gap stays between text and picture, and the gap has the picture's shape.
网格、文字、图片之间来回变：每一格是源在那一格画的东西，落下时是目标在那一格画的东西。格子多于“GPU 起点”时，粒子在显卡上模拟（旋度噪声、指针、波前），只有起点和终点由路径决定，所以交接那一帧和落地那一帧不变。指针推开粒子，按舞台放出一道波前。 = Changes back and forth between a grid, text and an image: each cell carries what the source drew there, and on landing what the target draws there. Above the “GPU threshold” the particles are simulated on the graphics card (curl noise, the pointer, fronts); only their start and end come from the path, so the hand-over frame and the landing frame are unchanged. The pointer pushes particles aside; pressing the stage sends a front.
三维物体是页面上的又一种东西：在布局给它的矩形里画，会松开、变形，可以按到。机件由代码里的基本形搭成：齿轮按齿数比啮合，凸轮推着从动杆；两种色调的平涂、画出的轮廓线，材质可以换。网格在一张离屏图里画出明暗、法线、深度和编号，再变成和文字一样的墨与近度：轮廓和棱都是“边”。 = A 3D object is one more thing on the page: drawn in the rectangle layout gives it, it loosens, deforms and can be pressed. The mechanism is built from basic shapes in code: gears mesh by their tooth ratio and a cam pushes its follower; two-tone flat shading and drawn outlines, with a material you can change. The meshes are drawn into an offscreen image of shade, normals, depth and ids, then become ink and nearness like text: outlines and creases are all “edges”.
每个风格是一份数据：主题、材质和它的参数、字体、标注、交互的性格，和一段过渡。过渡是几个步骤拼成的小程序（按形状揭开、错位的带、淡入、光条、色块、松开、分层、融化、检测框、刻、先画轮廓、撕开），每一步几个数。切到一个风格、进入这个风格的页面，都用目标风格的过渡；过渡中途再切，从此刻的画面接着过渡；输入一直可用。 = Each style is data: a theme, a material and its parameters, faces, annotation, a character for interaction, and a transition. The transition is a small program of steps (reveal by shape, slipped bands, fade, light bar, color blocks, loosen, layers, melt, detection frames, cut, outline first, tear), each a few numbers. Changing to a style or entering its page uses the target style's transition; changing again mid-way continues from the frame as it is; input always works.
低于平静速度时，滚动只是整像素的移动，材质的点阵跟着内容走；高于它，痕迹按速度渐强（平静速度到满速），停下后在“收住”的时间里消失。plain 只有一点拖尾；dot 一行一行地落在点阵上，留下荧光的点；halftone 和 print 的第二色错开；ascii 落在字格上，留下浅的字；glitch 偶尔整带错开。正文从不因此松开。 = Below the calm speed, scrolling is only a move by whole pixels and the material's lattice moves with the content; above it, traces grow with the speed (calm speed to full speed) and vanish within the “Settle” time after stopping. plain has only a little trail; dot falls row by row onto the lattice, leaving phosphor dots; halftone and print offset their second color; ascii lands on character cells, leaving faint letters; glitch now and then slips a whole band. Body text never loosens from it.
在这一页上，图片可以拖动。每次它移动，正文就重新断行：每一行先量出这一条带子里哪一段没有被挡住，再把能放下的字放进去。如果图片把一行分成左右两段，两段各排一行，读的时候从左到右。缝的宽度是一个数字，在下面可以改。 = On this page the picture can be dragged. Each time it moves, the text breaks its lines again: each line first measures which part of its band is not covered, then takes the words that fit. If the picture splits a line into a left and a right part, each part takes a line, read from left to right. The gap's width is a number you can change below.
这件事依赖的是图片真实的轮廓，而不是它的方框。图片带着透明的底，所以框的四角是空的，字可以一直排进树冠下面，挨着树干。圆形也一样：离圆心越远的行，留给文字的地方越宽。 = This depends on the picture's true outline, not its box. The picture has a transparent ground, so the corners of its box are empty and the text can run in under the crown, right up to the trunk. A circle works the same way: the farther a line is from the centre, the more room it leaves for text.
排版本身没有新的规则。断行仍然交给排版系统，它照常处理中文和 Latin words 的混排、标点和行宽；这里只是每一行给它一个不同的起点和宽度。所以字号、行高、字体都可以换，换了以后仍然绕得开。 = Typesetting itself has no new rule. Line breaking is still the typesetter's, which handles mixed scripts, punctuation and measure as usual; here each line only gives it a different start and width. So the size, the line height and the face can all change, and the text still goes round.
拖动的时候，你看到的是同一套布局在每一步重新计算的结果：没有动画曲线，也没有特殊的过渡。松手以后，页面就是一张普通的、安静的页面。 = While you drag, what you see is the same layout computed again at each step: no animation curve, no special transition. Let go and the page is an ordinary, quiet page.
