# 沿路径的文字

一行字放在一道行进的波上，指针再往里拉出一个鼓包。每个字形坐在曲线上，转到切线的方向。

## 公式

```
y(x) = A·sin(2πx/λ − ωt) + (m_y − y₀)·e^(−(x − m_x)²/σ²);  angle = atan y′(x)
```

## 参数

每个数在格子下面都是数字控件（键入、方向键、横向拖动），没有滑块。

| 名字 | 默认 | 范围 | 是什么 |
|---|---|---|---|
| `A` | 9 px | 0–40 | 波高 |
| `λ` | 150 px | 20–400 | 波长 |
| `ω` | 1.6 rad/s | 0–8 | 波速 |
| `σ` | 40 px | 6–160 | 拉动的宽度 |

## 怎么做的

`El::pose` 给出 `dy` 和 `angle`：字形的实例带着自己的变换（`Instance::xf`）。 代码在 `examples/lab/flow.rs`。
