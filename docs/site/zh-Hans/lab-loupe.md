# 球面上的文字

一段文字包在一个球上。字在段落里的位置是经度和纬度；球转动时，字放到它那一点投影的地方，按坡度压扁，按深度变暗；背面透过来，暗而且是反的。拖动转它；松手后滑行，慢慢回到空闲时的转速。

## 公式

```
λ = 2π(x − ½) + θ,  φ = 2.6(y − ½);  screen = c + R·(cos φ sin λ, sin φ);  ω → ω₀ at e^(−μt)
```

## 参数

每个数在格子下面都是数字控件（键入、方向键、横向拖动），没有滑块。

| 名字 | 默认 | 范围 | 是什么 |
|---|---|---|---|
| `R` | 0.46 ·h | 0.2–0.5 | 球的半径 |
| `ω₀` | 0.30 rad/s | 0–2 | 空闲时的转速 |
| `μ` | 1.6 /s | 0.1–8 | 转动减速的快慢 |

## 怎么做的

`El::pose` 给出 `dx`、`dy`、`sx`、`sy`、`tone` 和 `alpha`；`GlyphAt::span` 给出整段的范围。 代码在 `examples/lab/loupe.rs`。
