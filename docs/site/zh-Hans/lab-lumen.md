# 光照文字

一束光照在一段文字上。每个字形都完整地画出，只有色调随光的衰减变化，所以光离开的字是暗的，但仍是完整的字。

## 公式

```
L(d) = L0 + (1 − L0) · e^(−d²/r²)
```

## 参数

每个数在格子下面都是数字控件（键入、方向键、横向拖动），没有滑块。

| 名字 | 默认 | 范围 | 是什么 |
|---|---|---|---|
| `L0` | 0.22 | 0.05–1 | 静止时的色调 |
| `r` | 46 px | 8–160 | 光的半径 |
| `ω` | 0.35 rad/s | 0–2 | 空闲时路径的速度 |

## 怎么做的

`El::pose` 按每个字形的中心问它的姿态；色调相乘，轮廓不动。 代码在 `examples/lab/lumen.rs`。
