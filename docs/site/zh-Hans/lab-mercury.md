# 水银

元球：Σ rᵢ²/dᵢ² 等于 1 的地方是表面，画成等值线，里面用点填满。一个球带着弹簧跟着指针；靠近别的球时连成一团，拉开时分开。

## 公式

```
Σ rᵢ²/dᵢ² = 1;  m″ = k(p − m) − c·m′
```

## 参数

每个数在格子下面都是数字控件（键入、方向键、横向拖动），没有滑块。

| 名字 | 默认 | 范围 | 是什么 |
|---|---|---|---|
| `r₀` | 22 px | 4–40 | 指针的球 |
| `r` | 16 px | 4–40 | 漂移的球 |
| `k` | 120 | 10–600 | 弹簧的刚度 |
| `c` | 14 | 1–60 | 弹簧的阻尼 |

## 怎么做的

`field::Balls` 是一个标量场；`Drawing::dots` 和 `Drawing::contours` 画它。 代码在 `examples/lab/mercury.rs`。
