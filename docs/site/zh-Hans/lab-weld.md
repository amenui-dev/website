# Weld

距离场：每个标签片是一个圆角矩形，有自己的带符号距离，轮廓是它们的平滑并集。把一片拖到另一片旁边，两条轮廓会连出一道颈，中间标出间距；在 `join` 之内松手，两片就成了一组：一条轮廓，标签并排，一起拖动。把组里的一片快速拉开，它会断开。只按不拖，切换这一片的开关。

## 公式

```
d_i = |max(q, 0)| + min(max(qx, qy), 0) − r,  q = |p − c_i| − (h_i − r)
d = smin(d_1, …, d_6; 2k),  smin(a, b; k) = min(a, b) − max(k − |a − b|, 0)² / 4k
```

## 参数

| 名字 | 默认 | 范围 | 是什么 |
|---|---|---|---|
| `k` | 18 px | 0–40 | 融合宽度：相距 2k 的两片互不影响轮廓 |
| `join` | 12 px | 4–32 | 比这更近时松手，两片合成一组 |
| `tear` | 56 px | 24–120 | 一片离开它在组里的位置多远就断开 |
| `bands` | 2 | 0–3 | 轮廓外 6、12、18 px 的线 |
| `radius` | 6 px | 0–14 | 标签片的圆角 |

`[ scatter ]` 把标签片放到新位置，各自独立。焦点在一片上时：方向键移动 8 px，Enter 并入 `join` 之内最近的一片，Backspace 把它移出所在的组，空格切换开关。

## 怎么做的

并集在标签片外围以 2 px 网格取样（`field::Grid::sample`），用 marching squares 在 0、6、12 px 处描线（`Grid::contours`）。标签片都是元素：填色、标签（可选中的文字）和它们的组，组在树里是一个单独的元素。只有手拖动的东西和把标签片送回位置的弹簧会动，所以静止时这一格不画帧。代码在 `examples/lab/weld.rs`。
