# 一叠卡片

实验室样子的一叠卡片（`widgets::card_stack`）：悬停或按下一张卡，下面的展开。

## 公式

```
angle(n) = angle0 × falloff^n,  delay(n) = delay × n
```

## 参数

每个数在格子下面都是数字控件（键入、方向键、横向拖动），没有滑块。

| 名字 | 默认 | 范围 | 是什么 |
|---|---|---|---|
| `angle0` | 42° | 0–90 | 第一张转的角度 |
| `falloff` | 0.70 | 0.1–1 | 每下一张的比例 |
| `delay` | 28 ms | 0–200 | 错开 |

## 怎么做的

每张卡有自己的弹簧，带速度交接（DESIGN.md §1.24）。 代码在 `examples/lab/stack.rs`。
