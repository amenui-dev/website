# 一叠卡片

实验室样子的一叠卡片（`widgets::card_stack`）：悬停或按下一张卡，下面的展开。

## 公式

```
angle(n) = angle0 × falloff^n,  delay(n) = delay × n
```

## 参数

每个数在格子下面都是数字控件（键入、方向键、横向拖动），没有滑块。

| 名字 | 默认 | 范围 | 是什么 |
|---|---|---|---|
| `angle0` | 42° | 0–90 | 第一张转的角度 |
| `falloff` | 0.70 | 0.1–1 | 每下一张的比例 |
| `delay` | 28 ms | 0–200 | 错开 |

## 怎么做的

每张卡有自己的弹簧，带速度交接（DESIGN.md §1.24）：展开还没停稳时指针移到另一张卡，弹簧保留原来的速度，转向新的目标，而不是从静止重新开始。第 *n* 张卡比第一张晚 *delay × n* 开始，所以展开从最上面一张往下，收拢也一样。

卡片用实验室的样子画：贴近底色，带一条细线轮廓；指针下的那张用强调色。把 `falloff` 调到 1，每张卡转同样的角度；`delay` 为 0 时它们一起动。代码在 `examples/lab/stack.rs`。
