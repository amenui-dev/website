# 形体

一段文字自己聚拢，变成一个由它自己的字组成、慢慢转动、发着光的形体，再回到能读的文字。地址是 `#body`（场景里的第一个）；代码是 `examples/body.rs`，只用公开的接口写。

## 两种静止

一页文字：每个字都正好在排版放的位置（文字根本没有摆姿态）；和一个慢慢转动的形体。静止时没有半聚拢的样子：`gather` 由一个弹簧在 0 和 1 之间带着走；按下、空格或回车切换，在 `gather` 里键入小于 ½ 的数回到文字，否则去形体。

## 怎么做的

- 字数守恒：n 个字里的第 i 个，在它排版的位置和形体表面一条螺线上的第 i 个点之间来回。相邻的点在螺线上也相邻，所以文字按阅读顺序绕着形体走。每个字转到屏幕上螺线的切线方向，按坡度压扁，按深度缩放（`El::pose` 的 `dx`、`dy`、`angle`、`sx`、`sy`）。
- 形体是一个带符号距离场，取样成表面上的点：`rock` 是被两层噪声推进推出的球，`cloud` 是六个球的平滑并；都由 `seed` 决定。沿每个螺线方向从远处往里步进到表面，法线是场的梯度。
- 光：暗的底、一种色相。亮度按朝向和深度：正面接近白、带一点色相，边缘和背面是色相本身，背面暗。收尾的一遍加一点柔和的辉光。转动的时候，边缘的字从帧预算里掉下几个小点（文字状态时从来没有）。
- 拖动有惯性地转它；松手后滑行，回到空闲时的转速。指针靠近的地方，字回到自己在页面上的位置，透过这个口子能读到原来的句子；指针离开，口子合上。减少动态效果时不空转。

## 参数

| 名字 | 默认 | 范围 | 是什么 |
|---|---|---|---|
| `gather` | 0 | 0–1 | 文字（0）或形体（1） |
| `form` | 0 | 0–1 | 石头（0）或云（1） |
| `seed` | 7 | 0–99 | 形体的噪声或球 |
| `ω` | 0.18 rad/s | 0–1.5 | 空闲时的转速 |
| `open` | 140 px | 20–260 | 口子的半径 |
| `size` | 0.72 ·h | 0.3–1.2 | 形体最大的半径，文字高度的多少 |
