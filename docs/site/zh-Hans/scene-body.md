# 形体

落地页（`#body`）。一段文字先是一页能读的文字，然后自己聚拢，变成一个由它自己的字组成、慢慢转动、发光的形体，再回到能读的文字。代码是 `examples/body.rs`，只用公开的接口写；这一页只有这个场景，铺满窗口，没有外壳。

## 两种静止

文字：每个字都正好在排版放的位置（文字根本没有摆姿态）；形体：慢慢转动，镜头轻轻呼吸。弹簧在两者之间带着 `gather` 走；按下、空格、回车，或画面里“聚拢 / 散开”的标记切换。

## 怎么做的

- 这段文字的字是形体发亮的皮，字数守恒：n 个字里的第 i 个，在它页面上的位置和表面一条螺线上的第 i 个点之间来回，转到螺线的切线方向，按坡度压扁，正面的大。体积是第二群记号：从帧预算里要的一万一千个左右的小点，在背面的壳上和里面，聚拢时出现，散开时消失。
- 形体是带符号距离场：`rock` 是有大起伏、被削出几个平面的石头，`cloud` 是几个瓣的平滑并；种子决定它们。
- 一盏主光从左上方来：亮的一面接近白热，中间是这种形状的色相，背光的一面是它的深色，轮廓上一圈边光，按深度加雾，收尾的一遍加辉光和暗角。石头是骨白、余烬橙和深紫；云是浅青、青和靛蓝。
- 下面是一池倒影和一点光晕；灰尘在三种深度上慢慢飘，有视差；整个画面随指针轻轻移动。
- 拖动转它（松手后滑行，回到空闲的转速）。指针靠近的地方，字回到自己在页面上的位置，透过干净的口子能读到原来的句子。
- 控件是画面里的小标记，细线引到形体的轮廓上：形、种子、聚拢 / 散开、语言，以及去实验室和组件库的路。
