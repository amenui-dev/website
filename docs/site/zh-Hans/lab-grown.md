# 长成形状

限制在真实轮廓里的 Gray–Scott 反应扩散。形状是普通的元素，照常布局、不画；`El::on_outline` 把它真实的覆盖率作为遮罩送来，迷宫一样的花纹在里面长、到边为止。两个字母、一个开关控件和一个圆角方块轮流出现。

## 公式

```
u′ = Du∇²u − uv² + f(1 − u),  v′ = Dv∇²v + uv² − (f + k)v,  Du = 1, Dv = 0.5
```

## 参数

每个数在格子下面都是数字控件（键入、方向键、横向拖动），没有滑块。

| 名字 | 默认 | 范围 | 是什么 |
|---|---|---|---|
| `f` | 0.037 | 0.01–0.08 | 补给率 |
| `k` | 0.060 | 0.04–0.07 | 消耗率 |
| `steps` | 14 /frame | 1–40 | 每帧的步数 |
| `T` | 9 s | 2–30 | 每个形状的时间 |

## 怎么做的

`field::GrayScott`（有遮罩：遮罩外 u = 1、v = 0）；拖动处放入 v。 代码在 `examples/lab/grown.rs`。
