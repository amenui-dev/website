# 性能

只在有变化时画；只画变了的部分（两个框）；滚动只移动、不重新布局；长列表只造看得见的行；材质可以在一半分辨率上画松开的像素。

## 读数

按 F2（或影片底栏的 `fps`、组件库顶栏的“性能”菜单）打开读数，再按一次显示全部数字，第三次关掉。读数画在注释层的右下角，用等宽像素字。它只在本来就要画一帧时更新；最后一帧过去一秒后再更新一次，写上 `idle`，之后不再要帧。

| 读数 | 意思 |
|---|---|
| fps | 前一个数是最后两帧的间隔换算的即时帧率，后一个数是最近一秒实际画了几帧。静止时是 `idle`。 |
| frames | 画了多少帧、因为没有变化而跳过多少次、掉了多少帧（连续出帧时，间隔超过 1.5 个 60 Hz 帧）。 |
| update+layout | 处理消息、重建视图、布局用的时间（毫秒：最后一帧、一秒内平均、一秒内最大）。 |
| of it text | 其中排字（parley 断行）的时间。 |
| scene | 从布局好的节点造出实例的时间。 |
| gpu submit | 录制并提交 GPU 命令的时间（CPU 一侧）。 |
| 火花线 | 最近 120 帧，每帧一根，高度是它的开销，满格是 16.7 毫秒；从下往上依次是更新与布局、造实例、提交（提交用强调色）。 |
| dirty | 这一帧重画了屏幕的百分之几（两个框的并），以及录制了几个渲染遍。 |
| instances | 字形、形状、图片、三维视图各有多少个实例。 |
| particles | 正在飞的粒子数，以及它们走哪条路：计算着色器、浮点纹理，还是 CPU。 |
| tree | 节点总数、这次视图里有变化的节点数、累计的布局次数。 |
| text | 缓存里的段落数、累计排过几次字、字形图集用了多少。 |
| textures | 渲染器纹理内存的估计（全屏的几张图加字形图集），以及正在走的波前数。 |
| look | 当前材质、质量（材质那一遍的分辨率）和是否自动。 |
| device | 图形后端（WebGPU、WebGL2、Vulkan、Metal…）和适配器的名字。 |
| surface | 窗口的逻辑尺寸、设备像素比、当前语言。 |

一行模式只显示 fps、总开销、重画比例、实例数、材质和后端。
