# 丝

许多记号被漂移噪声的旋度带着走（没有源和汇，所以不会聚成团），再加上一张流场网格：指针的速度搅进去，然后慢慢消退。每个记号画成它这一步走过的那一笔。数量是向帧预算要的。

## 公式

```
ṗ = v · s · curl n(p/s) + u(p);  u += v_ptr · e^(−d²/24²);  u ×= e^(−dt/τ)
```

## 参数

每个数在格子下面都是数字控件（键入、方向键、横向拖动），没有滑块。

| 名字 | 默认 | 范围 | 是什么 |
|---|---|---|---|
| `N` | 1400 | 100–20000 | 要的记号数 |
| `v` | 22 px/s | 0–60 | 漂移的速度 |
| `s` | 60 px | 10–200 | 噪声特征的间距 |
| `τ` | 0.6 s | 0.05–3 | 搅动持续多久 |

## 怎么做的

`field::Swarm::advect`、`field::curl`、`field::Flow::stir`；`budget::grant(N)` 给出这一帧能动多少个。 代码在 `examples/lab/silk.rs`。
