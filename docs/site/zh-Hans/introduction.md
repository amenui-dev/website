# 介绍

gui-lab 是一个自己画每一个像素的界面框架，用 Rust 和 wgpu 写成，同一份代码跑在原生窗口和网页里。屏幕上的每一样东西——字形、形状、图片、三维的网格——都是一个带真实轮廓的实例，能按自己的轮廓松开、变形、再合上；它看起来怎样，是一种可以换的材质。

你写一个视图（状态 → 元素树）和一个更新（状态 + 消息 → 新状态），运行时做布局、输入、动画和绘制。
