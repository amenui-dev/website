# 项目结构

| 位置 | 是什么 |
|---|---|
| `src/el.rs` | 元素树和它的构造函数 |
| `src/ui.rs` | 运行时：布局、输入、焦点、滚动、动画 |
| `src/shader.wgsl` | 三遍绘制：实例、材质、标注 |
| `src/widgets/` | 组件，一个文件一个 |
| `src/i18n.rs`、`assets/i18n/` | 多语言和消息目录 |
| `src/gallery/` | 这份文档、实验室和场景 |
| `docs/DESIGN.md` | 设计契约 |
| `docs/site/` | 这些文档页的原文（两种语言） |
| `registry.json` | 组件清单 |
