# 从右到左

一行的方向是从右到左时，它从右边开始排：在这一行（或任何祖先）上写 `El::rtl(true)`，或者用一种从右往左读的语言。布局由 taffy 的 `Direction::Rtl` 完成；文字由 parley 按各自的方向排版，所以一段里混排拉丁字母和从右到左的文字时，逻辑顺序不乱。

## 哪些东西跟着方向

| 东西 | 从右到左时 |
|---|---|
| 一行的子元素 | 从右边开始。 |
| 按起点、终点写的内外边距 | 左右对调。 |
| 文字的对齐 | 从右边开始。 |
| 有方向的图标（箭头、尖角） | 由组件自己镜像，框架不管。 |

## 测试

`tests/i18n.rs` 检查从右到左的一行从右边开始；组件页的 RTL 一节把它的第一个例子放在从右到左的一行里。
