# 弹簧

弹簧上的质量，和底部面板用的是同一个 `gesture::Spring`，按解析解走。沿轨道拖动它；松手后它带着甩出的速度弹回去，下面画出最近两秒的轨迹。

## 公式

```
m·x″ = −k(x − x₀) − c·x′,  ζ = c / (2√(km))
```

## 参数

每个数在格子下面都是数字控件（键入、方向键、横向拖动），没有滑块。

| 名字 | 默认 | 范围 | 是什么 |
|---|---|---|---|
| `k` | 180 | 10–1200 | 刚度 |
| `c` | 6 | 0–80 | 阻尼 |
| `m` | 1 kg | 0.2–5 | 质量 |

## 怎么做的

`gesture::Animated::hold` 跟着手指；`to(x₀, v, now)` 把甩的速度交给弹簧。 代码在 `examples/lab/spring.rs`。
