# 弹簧

弹簧上的质量，和底部面板用的是同一个 `gesture::Spring`，按解析解走。沿轨道拖动它；松手后它带着甩出的速度弹回去，下面画出最近两秒的轨迹。

## 公式

```
m·x″ = −k(x − x₀) − c·x′,  ζ = c / (2√(km))
```

## 参数

每个数在格子下面都是数字控件（键入、方向键、横向拖动），没有滑块。

| 名字 | 默认 | 范围 | 是什么 |
|---|---|---|---|
| `k` | 180 | 10–1200 | 刚度 |
| `c` | 6 | 0–80 | 阻尼 |
| `m` | 1 kg | 0.2–5 | 质量 |

## 怎么做的

按住时 `gesture::Animated::hold` 让质量跟着手指，同时有一个速度记录器测它移动得多快。松手时 `to(x₀, v, now)` 把这个速度交给弹簧，所以甩出去会保留惯性，而不是突然停住。弹簧每帧按解析解求值，不是一步步积分，所以任何帧率下都一样。

公式那一行实时显示阻尼比 ζ：小于 1 时质量会冲过头并来回振荡，等于 1 时以不冲过头的最快速度回来，大于 1 时慢慢爬回去。轨道下面的曲线是最近两秒的位置。代码在 `examples/lab/spring.rs`。
