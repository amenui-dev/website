# 标注

第三遍是标注层：按真实的排版结果画框、编号、尺寸、引线、刻度尺，从不松开。`El::annotate(text)` 写一条说明，`{xy}` 换成元素中心的坐标。

有三种读的是整个范围，不跟元素：边注（`EDGE`：范围右边一条带刻度的细线，旁边竖排的衬线小字写着范围大小、指针坐标、材质和主题、最松的元素、场图里不为 0 的结点数）、波形（`OSC`：场图一行结点的能量，一个设备像素粗，`osc_amp`、`osc_y`）、电平条（`LEVEL`：平均能量和 `level_full` 的比）。`Ui::readout()` 记着画了什么；导出的树在根上带 `field: { level, nonzero }`。
