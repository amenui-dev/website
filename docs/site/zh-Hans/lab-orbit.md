# 轨道

圆轨道上的点，按开普勒的速度转；指针把它们拉离轨道，离开后弹回去。

## 公式

```
ω(r) = ω₁·r^−1.5;  δ″ = G(m − p)/(|m − p|² + 64) − kδ − cδ′
```

## 参数

每个数在格子下面都是数字控件（键入、方向键、横向拖动），没有滑块。

| 名字 | 默认 | 范围 | 是什么 |
|---|---|---|---|
| `ω₁` | 1.20 rad/s | 0–4 | 最内圈的速度 |
| `G` | 9000 | 0–40000 | 吸引 |
| `k` | 26 /s² | 1–200 | 回弹 |
| `c` | 5 /s | 0–30 | 阻尼 |

## 怎么做的

九十个点分在四条椭圆轨道上。每个点的角度按开普勒速度前进，所以内圈会追过外圈；此外每个点还带一个有自己速度的偏移，被指针的引力推开，由一个带阻尼的弹簧（`k` 和 `c`）拉住。引力式子里的 `+ 64` 让指针正好压在点上时它也不会变成无穷大。

指针离开后引力渐渐消失，弹簧把每个点带回自己的轨道。靠近指针的点用强调色。整个画面是一张由点和轨道笔画组成的图（`Drawing::dot`、`Drawing::polyline`）。代码在 `examples/lab/orbit.rs`。
