# 轨道

圆轨道上的点，按开普勒的速度转；指针把它们拉离轨道，离开后弹回去。

## 公式

```
ω(r) = ω₁·r^−1.5;  δ″ = G(m − p)/(|m − p|² + 64) − kδ − cδ′
```

## 参数

每个数在格子下面都是数字控件（键入、方向键、横向拖动），没有滑块。

| 名字 | 默认 | 范围 | 是什么 |
|---|---|---|---|
| `ω₁` | 1.20 rad/s | 0–4 | 最内圈的速度 |
| `G` | 9000 | 0–40000 | 吸引 |
| `k` | 26 /s² | 1–200 | 回弹 |
| `c` | 5 /s | 0–30 | 阻尼 |

## 怎么做的

点和圆环的笔画组成的图（`Drawing::dot`、`Drawing::polyline`）。 代码在 `examples/lab/orbit.rs`。
