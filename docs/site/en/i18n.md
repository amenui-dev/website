# Languages

Each language has a message catalog (`assets/i18n/zh-Hans.txt`, `en.txt`): `key = text`, `{name}` arguments, `key.one` / `key.other` plural forms. The locale lives in the state; `Ui::on_locale` makes it current while the view is built; switching is an ordinary message.

```rust
use amenui::i18n::Locale;
let l = Locale::En;
assert_eq!(amenui::t!(l, "widget.list.rows", n = 3), "3 rows");
```
