# Kern


两个字母之间的距离场：一个单词，每个字母是挂在弹簧上的物体，弹簧的静止长度在字母的轮廓之间量，不是在它们的方框之间。每一对下面标出两条轮廓之间的最小距离，上面标出它们之间的空白面积，最紧的一对用强调色。沿基线拖动一个字母：相邻的字母按规则跟着被推开，可以相碰，但不会重叠，也不会有字母出舞台；松手后弹回原位。

## 公式

```
metric:  x_i = 排版器给的笔位                        （字体自己的步进，含字偶距）
gap:     x_i = x_(i−1) + min dx : d(A, B + dx) ≥ target,   d(A, B) = min |p − q|, p ∈ A, q ∈ B
area:    x_i = x_(i−1) + dx : white(A, B + dx) = W     （W 为 metric 下各对的平均）
```

## 参数

| 名字 | 默认 | 范围 | 是什么 |
|---|---|---|---|
| `target` | 8 px | 0–40 | `gap` 下每一对最近处的距离；滑块停在让单词离舞台每条边都留 16 px 的最大值，面板上标出这个值 |
| `size` | 176 px | 44–220 | 单词最大的字号；实际字号是不超过它的最大整数 px，并让 `metric` 下的单词不超过舞台宽度的 80 % |
| `stiffness` | 600 | 100–900 | 弹簧 |
| `damping` | 44 | 10–60 | 弹簧 |

`[ metric ]`、`[ gap ]`、`[ area ]` 选择规则，字母沿弹簧移到新位置。`[ dims ]` 显示或隐藏测量。单词下面的输入框可以换词：最多 10 个字符，并且在 44 px 下放得进舞台。

## 怎么做的

单词用网站的无衬线字体 Noto Sans SC 排，三种规则在它上面给出三种不同的排法：`metric` 是排版器放每个字母的位置，含字偶距，由排版告诉单词的姿态（`GlyphAt::pen`）；`gap` 和 `area` 再按轮廓重新排这些笔位。像素等宽字体显不出这一点，因为每个字母都伸到格子里同样的两列，每一对的间距都一样。每个字母的墨迹来自页面的字体（`Ui::on_faces`、`pair::Faces`）；两条轮廓之间的距离和它们之间的空白是 `pair::gap` 和 `pair::area`，字母移动的每一帧都量一次；规则要求的间距由 `pair::spaced` 和 `pair::spaced_area` 求一次。单词是一段文字，所以能作为一个词选中和复制：每个字形从排版放下的位置移到它的字母该在的地方（`El::pose`）。代码在 `examples/lab/kern.rs`。
