# nightly


作品里的 W-04，夜里（23:10）。平静的深色水面，上面是满天星星。天上横着一行字，排在一条缓缓弯曲的线上，是构建日志：`nightly  ok  ok  ok  build 0412  ok  passing …`。字下面挂着一片极光，540 条光束从这行字往上升，褶皱处长，空隙处短。地平线上有一点橙色的小灯，带着一条标注 `KP 5   STEP 3/7`。曲线慢慢漂移，光束的长短也沿着它慢慢流动。指针靠近一处褶皱，那里就朝指针倾过去。按一下就运行构建的下一步：一个脉冲从这行字上离得最近的点向两边走，经过的光束变亮、变长半秒。第 7 步之后整片极光闪一下，标注变成 `PASSING`，构建号加一，新的一片极光淡入。地平线下面是极光破碎的倒影，每按一次就错开一次。

## 怎么做的

| 部分 | amenui |
|---|---|
| 天空、星星和水 | 用代码算出的一张图（天空从 `#070b16` 到地平线处的 `#12233a`，地平线在 80 % 高度，一条细线，水面，130 颗 1 或 2 px 的星星，很淡的颗粒），用 `El::picture` 显示 |
| 光束 | 一张 `Drawing`，里面是 1 px 宽的 `Drawing::ramp` 笔画，一次画完。每条从根部的 `#baffd8`，经过长度 30 % 处的 `#2fae8c`，到梢上完全透明，在下面的图上按 OKLab 混色。最高的那些在顶部三分之一转向强调色，是从三分之二处开始的第二段渐变 |
| 光束的长短 | 40 到 360 px，来自一个以每秒 12 px 沿线流动的噪声；构建号就是种子，所以每次构建的极光都不一样 |
| 那行字 | 一个只排一次版的 `text`，150 格 Departure Mono（不算空格是 100 个字形）。`El::pose` 把每个字形移到曲线上它的位置，随曲线转向，在光束根部下方 7 px；`recompose(false)` 让曲线漂移时不用重新排版 |
| 褶皱 | 指针 150 px 以内最高的那条光束，用一个大约 0.4 s 停稳的弹簧朝指针倾斜最多 18 px，旁边的光束在 60 px 内逐渐减弱 |
| 标注和倒影 | 两个标签和一条连到小灯的引线；地平线下 20 行短虚线，落在静止时光束最高的地方 |

手机上这行字从宽度的 6 % 排到 94 %，按桌面的字距放得下多少格就放多少格，在整词后截断；光束保持桌面的 2.35 px 间距：1024 宽时 384 条，390 宽时 146 条。

## 开销

作品醒着时，漂移按每秒 30 帧走（`Ui::ambient_fps`）；脉冲、闪光和褶皱的弹簧只在进行时才另外要帧。60 秒没有输入作品就停下。开启减弱动态效果时极光静止：按一下只记一步、错开倒影，没有脉冲和闪光，褶皱直接到位。

在 1440 × 900 下测得，动效按每秒 30 帧走。一帧里有 1,228 个实例。

| 一帧 | 平均 | 95 百分位 | 最长 |
|---|---|---|---|
| 静止，原生（CPU） | 0.08 ms | 0.08 ms | 0.88 ms |
| 脉冲，原生（CPU） | 0.78 ms | 0.91 ms | 1.02 ms |
| 静止，第一分钟，无界面 Chrome 2 倍缩放 | 1.96 ms | 2.60 ms | 14.2 ms |
| 脉冲，无界面 Chrome 2 倍缩放 | 1.57 ms | 2.60 ms | 2.70 ms |

浏览器里的数字用的是软件渲染器 SwiftShader 上的 WebGPU（不是显卡），真实机器上会更快。第一帧要排版整页，原生 62 ms，浏览器里 92.8 ms；浏览器第一分钟的数字不含它。

现在的配色是临时的：等绘图可以有自己的颜色，光束梢上的 `#1f5f86` 会回来。

代码在网站仓库的 `src/gallery/nightly.rs`。沿曲线排字见[沿路径的文字](lab-flow.md)。
